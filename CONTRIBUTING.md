# Contributing

Thanks for helping to grow **Awesome Proxmox VE**.

## Guidelines

- **Append your entry at the end of its category** — this list is ordered by addition,
  not alphabetically.
- One suggestion per pull request.
- Search the README and the previous pull requests first — yours may be a duplicate.
- Link directly to the project repository or its official site.
- Keep the description short and end it with a period.
- Check spelling and grammar, and remove trailing whitespace.
- Make the pull request title descriptive, e.g. `Add ProxMenux to Other Tools`.
- If you are the author of the project, say so in the description — self-submissions
  are welcome.

Entry format:

```markdown
- [Project Name](https://github.com/owner/repo) — Short description ending with a period.
```

New categories, and improvements to the existing categorization, are welcome.
Corrections — dead links, moved repositories, unmaintained projects — are as welcome
as additions.

Thank you for your suggestions!
